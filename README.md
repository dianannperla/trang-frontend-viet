# Trang Frontend Việt

## Giới thiệu
Trang Frontend Việt là một bộ công cụ giúp các nhà phát triển xây dựng giao diện web phù hợp với văn hóa và phong cách người dùng Việt Nam. Chúng tôi cung cấp nhiều thành phần UI, từ button, form đến các layout phức tạp, tất cả đều được thiết kế với trải nghiệm người dùng tối ưu.

## Tính năng
- **Component UI**: Gồm các thành phần như nút, biểu mẫu và bảng.
- **Hệ thống lưới**: Dễ dàng xây dựng bố cục responsive.
- **Hỗ trợ ngôn ngữ**: Dễ dàng thay đổi ngôn ngữ cho các thành phần.
- **Tính tương thích cao**: Tương thích với các framework phổ biến như React, Vue và Angular.

## Cài đặt
Để cài đặt, bạn chỉ cần chạy:
```bash
npm install trang-frontend-viet
```

## Sử dụng
Mỗi thành phần đều được tài liệu hóa đầy đủ. Bạn có thể tham khảo các ví dụ trong thư mục `docs`.
